# Starry Night Web Animation

A browser-based version of the Starry Night animation concept.

## Run locally

```bash
python3 -m http.server 8000
```

Then open:

- http://localhost:8000/

## Notes

- By default, the page loads a Wikimedia image URL.
- If remote loading fails because of network/CORS restrictions, use **Upload Local Image**.
- The animation is subtle and loop-oriented by design (calm atmospheric motion).
